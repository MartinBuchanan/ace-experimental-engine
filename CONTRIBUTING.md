# Contributing

This repository currently publishes documentation about an independent research project; it does not contain the private engine source or protected research material.

Public issues and documentation proposals should be concise, reproducible and limited to public information. Do not submit credentials, personal information, private correspondence, copyrighted reference material, private outputs, project files, databases, raw logs or material copied from a private task report.

Capability claims should state their evidence level. Documented, Exposed, Tested and Verified are not interchangeable.
