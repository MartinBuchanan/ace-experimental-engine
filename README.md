# ACE Experimental Engine

ACE Experimental Engine is an independent research project exploring a controlled experimental loop for vocal synthesis work:

**Objective → Experiment → ACE Studio → Generate/Render → Audio Analysis → Scoring → Evidence → Next Experiment**

The project aims to move beyond basic software control toward controlled experimentation, measurement, evidence, learning and iterative improvement. Its long-term direction is a closed loop that can propose a bounded experiment, execute supported steps, evaluate the result and use recorded evidence to choose what to try next.

This repository contains concise public documentation, architecture notes and milestone summaries. The engine source and protected research material remain in a separate private repository.

ACE Experimental Engine is an independent project. It is not affiliated with or endorsed by ACE Studio.
